Membership Information

What Can Be Verified?

The public verification portal provides essential information associated with an ICRI-STE membership record.

ID

Membership Reference

The unique reference assigned to the official ICRI-STE membership record.

✓

Membership Status

The current public status of the membership, such as Active.

R

Research Community

The membership type and ICRI-STE division associated with the member.

D

Issue Date

The date on which the membership record was officially issued.

V

Validity

The public validity period associated with the membership record.

I

Public Information

Only information available in the official public register is displayed.
